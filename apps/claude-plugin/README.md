# Jiscribe for Claude Code

The Claude Code plugin for [Jiscribe](https://github.com/gznnk/jiscribe): Claude
draws and edits `.jis` canvas diagrams — flowcharts, architecture diagrams,
sticky-note boards — and you can open the same file in a local viewer and edit it
alongside.

## Install

```
/plugin marketplace add gznnk/jiscribe
/plugin install jiscribe
```

## What is inside

- **The `jiscribe` MCP server** (`.mcp.json`), run from npm as
  `npx -y jiscribe-mcp@0.9`. It carries the canvas tools and the viewer.
- **The `jiscribe` skill** (`skills/jiscribe/`): what a Jiscribe canvas can hold
  and how to draw on it well, with the file format in
  `references/authoring-json.md` for reading or writing a `.jis` file directly.

## The skill is generated

`skills/jiscribe/SKILL.md` and `skills/jiscribe/references/authoring-json.md` are
generated by `@jiscribe/doc-schema` from the shape manifest and the hand-written
parts under `packages/doc-schema/parts/`. Edit those sources and run
`pnpm generate:schema`; edits made here are overwritten, and CI's `check:schema`
fails on the drift.
