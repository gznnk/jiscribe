# 手動テスト: data-gesture 統一後の回帰確認

`data-interactive` / 各所の `stopPropagation` / `data-native-wheel` を `data-gesture` に統一した変更（[gesture-attributes.md](./gesture-attributes.md) 参照）の回帰確認項目。ポインタ・ホイール・右クリックまわりは自動テストで完全には担保できないため、デモアプリ（`pnpm dev:demo`）で以下を確認する。

## 1. テキスト編集

| #    | 操作                                               | 期待結果                                                            |
| ---- | -------------------------------------------------- | ------------------------------------------------------------------- |
| 1-1  | 図形をダブルクリックして編集開始                   | textarea にフォーカスが当たり、キャレットが末尾に表示される         |
| 1-2  | 編集中にテキストを入力                             | 文字が入力でき、縦方向アライメント（top/middle/bottom）が維持される |
| 1-3  | 編集テキストをドラッグして範囲選択                 | 図形が動かず、テキストが選択される                                  |
| 1-4  | テキスト枠内の余白（テキストが無い部分）をクリック | フォーカスが外れず編集が継続する                                    |
| 1-5  | 内容があふれるまで入力し、textarea 上でホイール    | textarea 内がスクロールし、キャンバスは動かず編集も継続する         |
| 1-6  | あふれていない短いテキストの編集中にホイール       | キャンバスがスクロールするが編集は継続する                          |
| 1-7  | 編集中に Ctrl + ホイール                           | キャンバスがズームし、編集は継続する                                |
| 1-8  | textarea 上で右クリック                            | ブラウザ標準のコンテキストメニュー（コピー等）が表示される          |
| 1-9  | 編集枠の外側をクリック                             | テキストがコミットされ編集が終了する                                |
| 1-10 | 編集中に Escape                                    | 編集がキャンセルされる（キャンバスのショートカットは発火しない）    |

## 2. ObjectMenu スライダー（例: フォントサイズ・角丸など）

| #   | 操作                                  | 期待結果                                                                   |
| --- | ------------------------------------- | -------------------------------------------------------------------------- |
| 2-1 | スライダーのつまみをドラッグ          | 値がリアルタイムに変化し、図形に反映される。キャンバスの選択は解除されない |
| 2-2 | ドラッグ終了                          | 最終値が確定し、Undo 履歴に 1 件積まれる                                   |
| 2-3 | 数値入力欄をクリックして数字を入力    | 図形に反映される。クリックでキャンバスの選択が解除されない                 |
| 2-4 | 数値入力欄で Enter / フォーカスアウト | 値が確定する                                                               |

## 3. ObjectMenu カラーピッカー

| #   | 操作                           | 期待結果                                                             |
| --- | ------------------------------ | -------------------------------------------------------------------- |
| 3-1 | プリセットスウォッチをクリック | 色が反映される                                                       |
| 3-2 | CSS カラー入力欄に文字を入力   | クリック・入力でキャンバスの選択が解除されない。有効な色が反映される |
| 3-3 | 入力欄で右クリック             | ブラウザ標準のコンテキストメニューが表示される                       |

## 4. コンテキストメニュー

| #   | 操作                                          | 期待結果                               |
| --- | --------------------------------------------- | -------------------------------------- |
| 4-1 | 図形を選択して右クリック                      | コンテキストメニューが表示される       |
| 4-2 | callback 項目（コピー・貼り付け等）をクリック | アクションが実行され、メニューが閉じる |
| 4-3 | command 項目（最前面へ等）をクリック          | コマンドが実行され、メニューが閉じる   |
| 4-4 | メニュー項目以外のキャンバス上をクリック      | メニューが閉じる                       |

## 5. 基本ジェスチャーの非回帰（統一による副作用がないこと）

| #   | 操作                           | 期待結果                |
| --- | ------------------------------ | ----------------------- |
| 5-1 | 図形をドラッグして移動         | 正常に移動する          |
| 5-2 | 図形のハンドルでリサイズ・回転 | 正常に動作する          |
| 5-3 | 空白をドラッグして範囲選択     | 範囲選択できる          |
| 5-4 | 空白でホイール / Ctrl+ホイール | スクロール / ズームする |
| 5-5 | 右ドラッグでパン               | ビューポートが移動する  |
